# FOPTNET: ახალი საიტი, IT-სთვის

ერთგვერდიანი საიტია, სამ ენაზე (KA/EN/RU). აწყობა (build), ბაზა ან CMS არ სჭირდება, ფაილები სერვერზე უნდა აიტვირთოს ისე, როგორც არის.

## პაკეტის შიგთავსი

| ფაილი | რა არის |
|---|---|
| `index.html` | მთელი საიტი: დიზაინი, ტექსტები 3 ენაზე, რუკა, სქემები, ფორმები |
| `favicon.ico`, `assets/favicon.svg`, `assets/favicon-32.png` | ხატულა ბრაუზერის ჩანართისთვის |
| `assets/apple-touch-icon.png`, `assets/icon-192.png`, `assets/icon-512.png`, `site.webmanifest` | ხატულები ტელეფონის მთავარ ეკრანზე დასამატებლად |
| `assets/og-image.png` | 1200×630 სურათი, რომელიც ჩანს Facebook-ზე, LinkedIn-ზე, Messenger-ში და სხვაგან ბმულის გაზიარებისას |
| `robots.txt`, `sitemap.xml` | Google-ისთვის |
| `send.php` | ფორმების ელ. ფოსტაზე გაგზავნის მაგალითი (PHP) |

## ინსტალაცია (≈15 წთ)

1. **ძველი საიტის სრული ასლი შეინახეთ**, რომ საჭიროების შემთხვევაში დააბრუნოთ.
2. პაკეტის ყველა ფაილი საიტის root საქაღალდეში (`public_html` ან `www`) ატვირთეთ ისე, რომ `index.html` ძველი მთავარი გვერდის ადგილას აღმოჩნდეს. `assets/` საქაღალდის სტრუქტურა უცვლელად შეინარჩუნეთ.
3. თუ დომენი `www.foptnet.ge` არ არის, შეცვალეთ `https://www.foptnet.ge/` ამ ფაილებში:
   - `index.html`: 4 ადგილი, `canonical`, `og:url`, `og:image` და `twitter:image`.
   - `robots.txt`.
   - `sitemap.xml`.
4. საიტი HTTPS-ზე უნდა მუშაობდეს. HTTP → HTTPS გადამისამართება ჩართეთ.
5. **ძველი გვერდების ბმულები.** თუ ძველ საიტს ცალკე გვერდები ჰქონდა (მაგ. `/about.html`, `/contact.php`), ისინი 301 redirect-ით მთავარ გვერდზე, შესაბამის სექციაზე გადაიყვანეთ. ასე Google-ში და სხვაგან გაზიარებული ბმულები არ გაწყდება. `.htaccess`-ის მაგალითი:
   ```
   Redirect 301 /about.html   /#about
   Redirect 301 /contact.html /#contact
   Redirect 301 /services.html /#services
   ```
   სექციების მისამართებია: `#services`, `#network`, `#industries`, `#projects`, `#about`, `#group`, `#contact`.

## პარამეტრები: მხოლოდ ერთი ბლოკი `index.html`-ში

`<head>`-ში არის ეს ხაზი:

```js
window.FOPTNET_CONFIG = { formEndpoint: '', ga: '', demo: true };
```

| პარამეტრი | რას აკეთებს |
|---|---|
| `formEndpoint` | მისამართი, სადაც ფორმები გაიგზავნება, მაგ. `'send.php'`. ცარიელის შემთხვევაში არაფერი იგზავნება და მომხმარებელი ხედავს „დემო ვერსიაში ფორმა ჯერ არ იგზავნება“ |
| `ga` | Google Analytics 4 ID, მაგ. `'G-XXXXXXX'`. ცარიელია = გამორთულია |
| `demo` | `false`-ზე ფუტერიდან „დემო ვერსია“ წარწერა ქრება. საიტის ოფიციალურად გაშვებისას დააყენეთ `false` |

## ფორმები → ელ. ფოსტა

საიტზე ორი ფორმაა. ორივე `formEndpoint`-ზე აგზავნის **JSON POST**-ს. სერვერმა წარმატების შემთხვევაში უნდა დააბრუნოს HTTP 200, შეცდომისას ნებისმიერი სხვა კოდი. მომხმარებელი ორივე შემთხვევაში შესაბამის შეტყობინებას ნახავს.

**უმარტივესი ვარიანტი:** `send.php`.
1. გახსენით და შეცვალეთ 2 ხაზი:
   - `$TO`: ვის მიუვიდეს მოთხოვნები. რამდენიმე მისამართი მძიმით გამოყავით.
   - `$FROM`: გამგზავნის მისამართი, აუცილებლად თქვენი დომენიდან.
2. `index.html`-ში ჩაწერეთ `formEndpoint: 'send.php'`.
3. თუ ჰოსტინგზე PHP-ის `mail()` არ მუშაობს ან წერილები spam-ში ხვდება, გამოიყენეთ SMTP (PHPMailer) და დომენს SPF/DKIM ჩანაწერები დაუმატეთ.

> შემოწმებულია: `send.php` სწორ მოთხოვნაზე აბრუნებს 200-ს და წერილს აგზავნის. არასწორ ელ. ფოსტაზე აბრუნებს 422-ს, GET მოთხოვნაზე 405-ს, ხოლო ელ. ფოსტის სათაურში ჩაშენების მცდელობას (header injection) ბლოკავს.

PHP-ის ნაცვლად შეგიძლიათ ნებისმიერი სხვა სისტემა გამოიყენოთ (Node, Python, Formspree, Make/Zapier webhook), თუ ის JSON POST-ს იღებს.

### რა მოდის ფორმიდან

**საკონტაქტო ფორმა** (`form: "contact"`):
```json
{ "form":"contact", "name":"", "company":"", "email":"", "phone":"", "service":"", "capacity":"",
  "pointA":"", "pointB":"", "requestType":["…"], "message":"", "lang":"ka", "page":"https://…", "sentAt":"2026-…Z" }
```
**შეთავაზება რუკიდან** (`form: "enquiry"`):
```json
{ "form":"enquiry", "firstName":"", "lastName":"", "email":"", "company":"", "service":"", "bandwidth":"10G",
  "pointA":"თბილისი", "pointB":"ფოთი", "consent":true, "lang":"ka", "page":"https://…", "sentAt":"…" }
```
სავალდებულო ველებს (სახელი, კომპანია, სწორი ელ. ფოსტა, ხოლო შეთავაზებაში დამატებით თანხმობის ნიშანი) საიტი თავად ამოწმებს გაგზავნამდე. სერვერზე ხელახალი შემოწმება მაინც სასურველია.

## ტექნიკური შენიშვნები

- შრიფტები (Montserrat, Noto Sans Georgian) Google Fonts-იდან იტვირთება. თუ სერვერს Content-Security-Policy აქვს, დაუშვით `fonts.googleapis.com` და `fonts.gstatic.com`, ხოლო GA-ს ჩართვისას `www.googletagmanager.com` და `www.google-analytics.com`.
- სხვა გარე ფაილი ან ბიბლიოთეკა საიტს არ სჭირდება. რუკა და სქემები SVG-ით და JavaScript-ითაა აწყობილი პირდაპირ `index.html`-ში.
- `localStorage`-ში ინახება მხოლოდ არჩეული ენა (`foptnet-lang`). cookie-ები არ გამოიყენება, GA-ს ჩართვამდე.
- გატესტილია Chrome-ის ძრავზე 5 ზომაზე: 1440, 1024, iPad Mini, iPhone 13 და 360px. 378 ფუნქციური შემოწმებიდან JavaScript-ის შეცდომა არცერთზე დაფიქსირებულა. გაშვებამდე სასურველია Safari-სა (Mac/iPhone) და Firefox-ში ხელით გადახედვა.
- iframe-ში ჩასმა **არ არის რეკომენდებული**. გვერდს აქვს ფიქსირებული ნავიგაცია და მობილურის მენიუ, ამიტომ სწორად მუშაობს მხოლოდ, როცა ცალკე გვერდად ან მთავარ გვერდად დგას.
